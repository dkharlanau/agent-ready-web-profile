**State:** 34 researched, primary-source-backed **review candidates**. They are NOT 34 new shipped features, SEO ranking factors, or an instruction to publish 34 pages. Human/product review must precede activation. The latest verified owner data and current source documents outrank any older snapshot.

**Scope:** The existing Goose/ARWP core, with opt-in vertical applicability to real client sites. Raw owner evidence, credentials, private query/page exports and protected implementation receipts remain outside this public repository.

## The decision from eight role passes

**Website owner:** Show the next justified change and what evidence would change the recommendation; don't lead with an unearned "AI ready" score.

**Technical SEO:** Repair observed access/canonical/indexing inconsistencies before testing optional media, feeds or agent protocols. Distinguish actual Google indexed version from an ordinary HTTP response and Search impressions.

**GEO / answer specialist:** Bing now exposes a query-to-cited-page relationship, topics, intents and query-scoped Citation Share. These are potentially more useful than an external synthetic prompt score when the real owner has enough data. Do not treat citation counts as sessions or individual answers.

**Editor:** The October 2026 guidance sharpens the requirement for original useful work and careful review of AI-assisted text **and metadata**. Build one defensible original asset rather than paraphrasing twenty generic guides.

**Architect:** ACP merchant feeds, WebMCP tools and Google UGC fresh ingestion have real documented requirements and scope limits. None is a universal GEO markup switch. Use existing Goose engines, avoid a new framework before a proof case.

**Rights/privacy reviewer:** Treat training, search, user-agent interaction, paid ads, content-use preferences and private account evidence as separate decisions. Watch the IETF draft without advertising draft syntax as settled standard.

**Product manager:** 7 P0 entries concern credibility, evidence and existing work; 19 P1 entries are applicable only with real owner data or qualifying site surfaces; 8 P2 entries are gated/watch/restricted opportunities. **Current M1 proof-before-expansion gate stays intact.**

**Skeptical investor:** Not a win until a site completes source-verified recommendation → exact deployment → provider-native observation → reviewed keep/revise/stop. Neutral and negative results belong in the learning corpus.

## Do not turn these into tactics

- **Do not** use the UGC Fresh Data Program for standard editorial/project sites; only qualifying UGC platforms can even apply.
- **Do not** claim a ranking benefit from `llms.txt`, WebMCP, AIPREF, a Content Signals directive, schema volume, synthetic GEO scores, Indexed URL counts or a sitemap ping.
- **Do not** use FAQ rich results as a 2026 Google growth strategy: Google retired the feature.
- **Do not** conflate OAI-SearchBot with GPTBot, ChatGPT-User, OAI-AdsBot, or Cloudflare Search/Agent/Training categories. A policy requiring one does not grant the others permission.
- **Do not** equate a paid ChatGPT Ads feed with organic ACP discovery, or an approved partner-only ACP with open signup.
- **Do not** copy external protected Search Console/Bing/GA4 observations into the public repository. Product/account-specific work requires actual permission and comparable windows.
- **Do not** call preview-topic labels, Citation Share, Search Console Web impressions, a crawl request and actual useful-action completions a single metric.

## Execution slices; no new major product module

**Slice 1 — source integrity:** Fix source-watch handling of unrelated redirects and add a current OpenAI crawler reference; preserve the old original claim/Atlas citation history until independently reviewed. Keep all WATCH→ADOPT transitions human-review-only.

**Slice 2 — human editorial review:** Use the existing Goose writing rules to audit a bounded set of high-visibility pages/recommendations and verify visible claims alongside generated snippets, alt text and JSON-LD. Preserve good copy; don't rewrite everything by formula.

**Slice 3 — first owner proof:** Continue the frozen Ptichi 12/6 cohort through exact production, index state, *separately* scoped final owner Web and AI performance data, and an actual decision. Do not assume a scheduled window is final owner evidence.

**Slice 4 — one eligible vertical pilot:** Only when the matching business/account exists, choose one: Bing grounded citation job, authentic video key moments, a real commerce Stable feed, an eligible publisher Preferred Source flow, or a WebMCP form trial. Implement only that bounded problem.

**Slice 5 — learning/retirement:** Preserve neutral/negative trials, source supersession and decisions not to implement in the existing review mechanism. A review worksheet does not promote a live Goose rule.
