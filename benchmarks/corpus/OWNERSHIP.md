# Ownership labels

`independent` means the benchmark project owner does not control the target site or its discovery metadata.

`project-reference` means the target is part of the original ARWP-owned/reference implementation suite. These sites are valuable engineering fixtures but do not count as independent evidence.

`example-only` means a file demonstrates the fixture shape and must never be scored.

If ownership is ambiguous, do not count the site as independent until it is resolved.
