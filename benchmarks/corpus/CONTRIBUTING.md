# Contributing benchmark sites

For an external site to count in resolver utility results:

1. confirm the target is public HTTPS;
2. label ownership honestly;
3. review the relevant discovery/runtime evidence manually;
4. list every acceptable interface for each applicable intent;
5. keep protocol status accurate (standard/community/experimental);
6. do not infer capabilities from marketing text;
7. do not use Resolver output alone as ground truth;
8. record review date;
9. preserve raw per-site benchmark outcomes, including failures.

Use the resolver interoperability failure issue template when a site reveals a concrete resolver bug or missing mapping.
