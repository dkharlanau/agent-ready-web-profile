# Site Improvement Plan

ARWP's Site Improvement Plan is the bounded orchestration layer above Search/AI Growth, Entity Graph remediation, page semantics and internal-link observations.

It selects a small implementation backlog instead of emitting a universal score.

## Ordering

1. P0/P1 before P2/P3.
2. Grounded first-party evidence before direct observation, source-backed guidance, manual review and advisory items.
3. Concrete targets/proposals before open-ended review when priority and evidence are otherwise equal.
4. Lane diversity inside a priority band.

Each action includes verification and measurement hooks. The planner does not mutate repositories, invent missing facts, predict ranking lift or infer causality from traffic movement.
