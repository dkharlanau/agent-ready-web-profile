## ARWP website quality

This site follows the Agent-Ready Web Profile (ARWP) as an evidence-backed quality/interoperability playbook.

When changing public pages, metadata, navigation, agent discovery, structured data, or site-quality CI:

1. use the `arwp-prepare-site` Agent Skill when available;
2. preserve this repository's framework/design/content conventions;
3. fix Search/indexability/canonical/freshness problems before optional agent features;
4. prefer upstream standards over new custom manifests;
5. add `llms.txt`, Agent Skills, ARD, OpenAPI/MCP/A2A/WebMCP or ARWP profile fields only when useful and truthful;
6. do not add `meta keywords` or FAQ schema as ranking cargo cult;
7. run the site's build/tests and ARWP audit/growth verification before completion;
8. never claim ARWP or metadata guarantees Google ranking, AI citation, recommendation placement, authorization, security, or universal agent readiness.
