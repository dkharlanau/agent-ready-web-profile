# ARWP Growth Loop checklist

Use this as a durable review artifact for a target site. Mark manual and owner-data checks honestly.

## 1. Search foundation
- [ ] Priority pages return HTTP 200.
- [ ] Intended search crawlers are not accidentally blocked.
- [ ] No unintended `noindex`, `nosnippet` or equivalent blocker exists.
- [ ] Canonical URLs are stable and correct.
- [ ] Sitemap is reachable and `lastmod` reflects significant changes.

## 2. Content and retrieval
- [ ] Priority pages provide original experience, evidence, examples or analysis.
- [ ] Important claims are supported by primary/reliable sources where appropriate.
- [ ] Headings describe real questions/decisions rather than generic sections.
- [ ] Important sections have stable, addressable anchors.
- [ ] Internal links connect hubs to priority answer/evidence pages.
- [ ] Author/entity/provenance information is accurate where readers expect it.

## 3. Recommendation and visual surfaces
- [ ] Discover is relevant to this content type; otherwise mark not applicable.
- [ ] Priority recommendation content has useful representative imagery.
- [ ] Large-image previews are not accidentally restricted when desired.
- [ ] Preferred Sources is used only when a repeat-reader use case exists.

## 4. AI access and agent interoperability
- [ ] Search/AI-answer access policy is intentionally separated from training policy where the provider supports separate controls.
- [ ] `llms.txt`, Agent Skills, ARD/API/MCP/A2A/WebMCP/ARWP surfaces are published only for real capabilities/use cases.
- [ ] Runtime capabilities have runtime evidence; static metadata alone is not marked conformant.

## 5. Measurement
- [ ] Baseline date/window is recorded.
- [ ] Relevant Google Search/generative/Discover metrics are captured where available.
- [ ] Relevant Bing AI citation data is captured where available.
- [ ] ChatGPT/referral evidence is captured where available.
- [ ] Real product outcome is recorded: conversion, task completion, return use, or another site-specific goal.

## 6. Decision
- [ ] Selected hypothesis IDs are recorded.
- [ ] Implementation checks are complete.
- [ ] External/manual checks remain explicitly external/manual.
- [ ] Result is marked keep / revise / revert / retire.
- [ ] Neutral and negative evidence is preserved.

Passing this checklist does not guarantee indexing, ranking, Discover placement, AI citation or recommendations.
