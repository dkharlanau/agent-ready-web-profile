# ARWP non-commodity content review

Use this checklist on pages that matter for Search, AI citation, referral or conversion. It is a human editorial review, not an automated ranking score.

## Purpose

- [ ] The page has a clear primary purpose for a real audience.
- [ ] It would still be worth publishing if search traffic did not exist.
- [ ] It does not exist only to cover a query variant, fan-out phrase or trending keyword.

## Unique value

- [ ] The page contains first-hand experience, original analysis, original data, original examples or a defensible point of view.
- [ ] It adds material value beyond summarizing what other pages already say.
- [ ] Important claims are supported by direct evidence, primary sources, measurements, screenshots, data, code, examples or clearly scoped expert judgment where appropriate.
- [ ] Negative results, limitations and uncertainty are not hidden.

## Who

- [ ] A reader can tell who created or reviewed the content where authorship is expected.
- [ ] The byline links to a real author/profile/about page with relevant background.
- [ ] Article structured data identifies the same author accurately.

## How

- [ ] When creation method matters, the page explains how the result was produced, tested, measured or researched.
- [ ] If substantial AI/automation was used and readers would reasonably care, the role of automation is disclosed appropriately.
- [ ] Original images, screenshots, charts or video are used when they strengthen evidence rather than decorate the page.

## Freshness

- [ ] Visible publication/update dates are truthful.
- [ ] `datePublished` and `dateModified` match the real page history where Article markup is used.
- [ ] `dateModified` changes only after a meaningful update, not to manufacture freshness.
- [ ] Sitemap `lastmod` reflects significant page changes accurately.

## Structure and citation readiness

- [ ] Headings describe real sections and have stable fragment IDs where useful.
- [ ] Evidence-bearing sections are visible without requiring a collapsed tab/accordion state.
- [ ] The page keeps URL fragments intact and does not force scroll position on load.
- [ ] Canonical URL is explicit and duplicate variants are minimized.
- [ ] External citations prefer primary sources when available.

## Entity identity

- [ ] Organization/Person identity is consistent across the site, author pages and structured data.
- [ ] `sameAs` links point only to genuine authoritative profiles.
- [ ] Publisher, author and product/project names are used consistently.

## Governance

- [ ] Third-party, sponsored, partner or white-label sections fit the site's real editorial purpose and are not published mainly to exploit the host domain's ranking signals.
- [ ] `llms.txt`, ARD, AGENTS.md or other agent files exist only for real interoperability consumers, not as claimed Google ranking hacks.
- [ ] FAQ markup is not being added solely for a Google FAQ rich-result advantage; Google deprecated that feature in 2026.

## Measurement

- [ ] Google Search Console is configured and Generative AI performance is reviewed.
- [ ] Bing Webmaster Tools AI Performance is reviewed if relevant.
- [ ] Search Console platform properties are configured for relevant Instagram, TikTok, X or YouTube properties.
- [ ] AI/search changes are measured before and after, without automatically attributing causality to ARWP.
