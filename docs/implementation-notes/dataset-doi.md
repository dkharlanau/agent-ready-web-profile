# Dataset DOI implementation note

The DOI requirement is scoped to the dataset product of a target site, not to ARWP itself. ARWP may have its own software/research citation identifiers separately.

A target site such as CBT Cards or Metkagram can simultaneously be a product/editorial site and contain a reusable corpus. In that case ARWP activates the dataset-publication track for the corpus and expects an externally archived, versioned DOI-backed release when persistent citation is appropriate.

The live site remains mutable; the archived DOI release remains frozen and reproducible.
