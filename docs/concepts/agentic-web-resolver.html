Defined term / ARWP

Agentic web resolver

Status: project-definedReviewed 2026-09-05CC BY 4.0
Software that discovers multiple machine- and agent-facing interfaces exposed by a website, preserves provenance, reports conflicts and selects an interface for a concrete intent.

Required properties in the ARWP usage

  • Multi-surface: it can consider ordinary web discovery and protocol/community surfaces rather than one manifest only.
  • Evidence-preserving: it records where each candidate came from.
  • Conflict-visible: contradictory declarations are not silently collapsed.
  • Intent-aware: selection depends on the requested task, such as read, search, structured data, tools or agent interaction.
  • Conservative: metadata presence is not automatically treated as runtime conformance or permission.

Why ARWP uses the term

The project started with a publisher profile, then moved toward a resolver-first architecture because public websites can legitimately expose several overlapping discovery mechanisms. The term gives that interoperability function a stable name inside the project.

Boundary

ARWP defines this term for its own product/model. The page does not claim that “agentic web resolver” is a registered or universally adopted standards term.
