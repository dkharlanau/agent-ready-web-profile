# Catalog review: fixing the evidence, not just adding patterns

Review edition 1.0.0 · 8 September 2026 · corpus 1.7.0.

This pass individually reviewed 23 previously unreviewed comparison, service and localization practices. Nine needed source or instruction corrections. Fourteen gained scoped review notes without operational changes. All 23 remain **inferred**: reading a source does not turn a project workflow into a documented ranking mechanism.

## What changed

| Finding | Correction |
| --- | --- |
| A general cost-comparison rule depended only on Cloudflare limits. | Use the price-component vocabulary as a bounded basis; keep scenario arithmetic a project procedure. |
| Migration and translation maintenance advice depended on Stripe upgrades. | Separate practical comparison evidence from honest freshness guidance; describe our workflows as proposals. |
| A service delivery process cited GitHub release management. | Replace that analogy with process-transparency guidance and explicitly retain the service sequence as our proposal. |
| Cell-level comparison citations referenced private HTML data attributes. | Remove the unrelated syntax reference; keep visible evidence provenance as our convention. |
| Contact testing relied on general page structure. | Use the WAI forms tutorial for interaction, keep actual delivery a separate test, and require an authorized test procedure. |
| Locale prioritization implied a Search Console language breakdown. | Use country/page/query evidence with a reviewed locale-URL map; page language is not visitor language. |
| Comparison relationship disclosure omitted link qualification. | Review visible disclosure and paid-link attributes separately. |

## What a review now records

Each reviewed pattern names the exact source section and separates what the source says from what the project proposes. A vocabulary property can justify a data representation; it cannot alone prove an editorial process, legal compliance, conversion uplift or ranking effect. An authoritative but unrelated source is still weak support.

Review-only changes advance the pattern patch version. Changed instructions or source references advance its minor version. The corpus preserves the complete 1.6.0 predecessor and every stable ID. The machine-readable review record lists before/after versions and source references so readers can inspect what changed.

## Remaining work

The library still contains 219 patterns. Individual review coverage is now 126; 93 historical records remain unreviewed. The source register has 118 entries. This report does not certify the entire catalog or every prior reviewed record as permanently current. It also does not claim search, AI citation or revenue gains.

The next passes should apply the same test to technical access, architecture, datasets, media, editorial and measurement practices: direct support, valid analogy or unsupported assertion? Keep useful project proposals explicitly inferred; replace unrelated evidence and revise operational mistakes before increasing the reviewed count.
