What the result shows

All five profile-only misses were for the read intent. The profile supplied valuable retrieval, structured-data and tool declarations, while ordinary observed-web discovery supplied the reviewed llms.txt read surface. Combining both evidence families produced 25/25 correct decisions.

Interpretation: on this owner-controlled suite, ARWP Profile works best as complementary publisher metadata rather than a replacement for normal web discovery.

Evidence and boundaries

This is implementation/regression evidence. It is not independent adoption evidence and does not prove search-ranking gains, AI recommendation/citation gains, answer quality, token savings, runtime MCP/A2A conformance or security trust.
