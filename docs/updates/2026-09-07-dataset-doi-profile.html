ARWP update · 7 September 2026

Dataset-bearing websites now get a separate publication audit.

ARWP no longer treats a directory of JSON files or a generic CITATION.cff as sufficient dataset maturity. When a site contains a genuine reusable corpus, the dataset is evaluated as its own versioned and citable data product.

What the module checks

  • canonical Schema.org Dataset metadata;
  • explicit release version and reuse rights;
  • methodology, provenance and limitations;
  • stable downloadable distributions;
  • frozen-release integrity/checksum evidence;
  • an externally issued DOI or equivalent persistent archive identifier.

A genuine corpus with no observed DOI is reported as dataset-doi-missing. ARWP recommends preparing and freezing the intended release, publishing it through an external archive such as Zenodo, verifying the issued DOI, then exposing that DOI consistently in Dataset metadata and citation surfaces.

What this does not mean

ARWP does not recommend inventing thin datasets for ordinary websites. DOI publication is a citation, provenance and reproducibility mechanism; it is not a Search ranking factor, quality certificate or guarantee that an AI system will cite the site.
