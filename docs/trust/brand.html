Product identity / 7 September 2026

SiteCurrent is the product. ARWP is the technical foundation.

SiteCurrent is the human-facing brand for adaptive website improvement. Agent-Ready Web Profile (ARWP) remains the open-source project, repository/package identity, profile terminology and interoperability foundation.

The product promise

The web changes continuously. SiteCurrent connects current Search, AI and agent guidance to the website that actually needs to change: detect what applies, resolve the exact work, verify the implementation and measure what happened afterward.

Found. Understood. Cited. Used. is the benefit rhythm. These are product goals, not guaranteed ranking or citation outcomes.

The technical identity

Use Agent-Ready Web Profile or ARWP for the open-source repository, npm package, Resolver, profile contracts and compatibility/interoperability references.

Visual identity

The SiteCurrent mark combines directional current strokes with a stable site node: the environment keeps moving while the target website is repeatedly brought back into a current, verified state.
