# Stratified external corpus direction

The next external benchmark expansion should not be a random increase in site count.

It should happen after Resolver union closes the current decision-quality gap on the frozen 20-site corpus.

Proposed independent strata:

| Stratum | Example capability question |
| --- | --- |
| documentation | Can the Resolver find the best readable/searchable docs surfaces? |
| developer/API portal | Can it distinguish API descriptions from search/tool semantics? |
| public knowledge base | Can it select retrieval/index surfaces without inventing operations? |
| dataset/research site | Can it distinguish distributions, schemas and retrieval? |
| agent-native site | Can it discover MCP/A2A/Skills while preserving protocol/runtime boundaries? |

Each stratum should publish separate intent accuracy and mismatch taxonomy. A single aggregate remains useful, but it must not hide that one site class is weak.

Owner-controlled reference sites remain a separate cohort and never count toward independent adoption/interoperability coverage.
