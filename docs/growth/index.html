ARWP Growth

Connect a site. Get a defensible improvement backlog.

The Growth Profile combines observable Search/AI-access blockers with current platform guidance, editorial quality contracts, identity metadata, measurement and agent interoperability. It produces priorities, not a universal score.

Trend-aware by design

Growth planning now consumes the ARWP Trend Radar. The radar separates emerging WATCH signals from primary-source-backed ADOPT changes and evidence-backed MEASURED changes.

Only applicable ADOPT/MEASURED trends enter a site plan. Newness alone never creates a recommendation or ranking claim.

node bin/arwp-trends.mjs list --since=30 --exclude-retired
node bin/arwp-growth.mjs https://example.com --vertical=editorial --json

What it optimizes

Search eligibilityHTTP/indexability, robots access, snippet eligibility, canonical/freshness foundations.
AI discoverabilityOAI-SearchBot access, authenticated platform inclusion controls, provider-specific AI use policy, Preferred Sources and citation-ready sections.
Entity identityOrganization/Person identity, author profile links, sameAs and structured publication metadata.
Content qualityHuman review for non-commodity value, first-hand evidence, who/how/why, useful visual proof and topical purpose.
MeasurementGoogle Generative AI performance, Bing AI Performance, ChatGPT referrals and social/video Search Console properties.
Agent operabilityAccessibility/runtime evidence plus ARWP/ARD/MCP/A2A/WebMCP, never mislabeled as Google ranking factors.

Run it

node bin/arwp-growth.mjs https://example.com
node bin/arwp-growth.mjs https://example.com --vertical=software-product --json
node bin/arwp-growth.mjs https://example.com --output=arwp-growth.json

For a recurring loop, copy templates/growth/github-action.yml into the target website repository and set ARWP_TARGET.

Priority model

  • P0 — observable eligibility blocker.
  • P1 — high-value quality, identity, access, freshness or governance action.
  • P2 — acquisition, measurement or optional multi-format opportunity.
  • P3 — lower-priority experiment.

No aggregate readiness or ranking score is produced.
