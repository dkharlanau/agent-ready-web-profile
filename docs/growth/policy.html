ARWP Growth · Owner intent

Tell ARWP what the site is actually trying to achieve.

A crawler cannot decide whether you want ChatGPT Search, model training, Preferred Sources or commerce/local guidance. Growth Policy makes those decisions explicit before ARWP turns evidence into implementation work.

Policy controls

  • Google Search target
  • Google generative Search target
  • ChatGPT Search target
  • Bing AI target
  • browser-agent target
  • model-training allow/deny/unspecified
  • real-time AI input allow/deny/unspecified
  • content reuse: immediate/reference/full/unspecified
  • publisher/author identity expectations
  • measurement surfaces
  • Preferred Sources opt-in

Site class

Select one primary class so vertical requirements do not pollute the universal baseline.

  • documentation
  • editorial
  • software-product
  • commerce
  • local-business
  • research-dataset
  • general

Example

{
  "policyVersion": "0.1",
  "target": "https://example.com/",
  "siteClass": "software-product",
  "goals": {
    "googleSearch": true,
    "googleGenerativeSearch": true,
    "chatgptSearch": true
  },
  "aiUsagePolicy": {
    "modelTraining": "deny",
    "realTimeAiInput": "allow",
    "contentReuse": "reference",
    "emitCloudflareContentSignals": true
  }
}

Download the complete example JSON.

Compile it

node bin/arwp-growth.mjs https://example.com --json > arwp-growth.json
node bin/arwp-growth-policy.mjs validate growth-policy.json
node bin/arwp-growth-policy.mjs compile arwp-growth.json growth-policy.json --json

The implementation manifest filters out actions the owner did not select and emits a desired state for crawler policy, structured identity, measurement and optional Preferred Sources.

Growth Policy is owner intent, not platform approval. Its output must be merged with existing legal, security, crawler and business requirements.
