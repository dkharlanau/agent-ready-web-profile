LEARNING SYSTEM

Observe. Challenge. Retire.

Adding recommendations is easy. Goose is designed to also weaken or remove them when evidence changes.

01

External evidence

Separate provider requirements from independent observations and expert experiments.

02

Winner Observatory

Track entrants, drops, top-10 persistence and citation persistence for frozen query cohorts.

03

Controlled cohorts

Freeze treatment, controls and queries before outcomes are visible, then block measurement until production parity.

04

Recommendation review

Move advice through fresh, review-due, challenged, contradicted and retire-candidate states without silent registry mutation.

EVIDENCE IS NOT ONE SCORE

Keep the stages apart.

A passing implementation is not a deployment, a deployment is not exposure, and a citation is not a useful visit.

01

Implementation

Did the repository change exist and pass checks?

02

Deployment

Is that exact implementation live?

03

Exposure

Did Search/AI systems expose the page?

04

Citation

Was the page cited, and did the citation persist?

05

Visit

Did identifiable traffic arrive?

06

Useful action

Did the visit lead to a relevant product action?
