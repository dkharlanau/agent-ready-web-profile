Agent-Ready Web Profile

ARWP is open-source developer tooling for evidence-backed website growth, Search and AI visibility, and agentic-web interoperability. The product page gives the software one stable visible identity instead of scattering its description across documentation pages.

SoftwareApplicationFree / Apache-2.0v0.2.0

What the product does

  • audits Search and AI-search eligibility and implementation opportunities;
  • turns current platform guidance into testable growth hypotheses;
  • discovers heterogeneous agent-facing website interfaces and preserves provenance/conflicts;
  • tracks crawler policy, evidence receipts and owner-side visibility measurements.

Availability

The software is available without payment from the public GitHub repository and npm package. The structured data therefore uses an Offer with price: 0.

GitHub repository · npm package

Why there is no rating in the schema

Google's SoftwareApplication rich-result documentation requires a genuine rating or review in addition to the application name and offer price. ARWP does not currently have grounded public rating data, so no rating or review is fabricated. The schema remains useful as truthful software semantics without claiming rich-result eligibility.
