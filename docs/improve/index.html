Site Improvement Plan

ARWP combines Search/AI Growth actions, grounded Entity Graph remediation, page semantics and internal-link observations into a small ordered backlog. It does not output a universal SEO/readiness score or promise ranking lift.

Why another layer?

Audits become less useful when every warning competes equally for attention. The planner caps the default backlog at eight actions and orders them by explicit priority, evidence quality and actionability, while preserving lane diversity.

Evidence order

  1. Grounded first-party — repository evidence supports a concrete proposal.
  2. Direct observation — the current public page or graph shows the issue.
  3. Source-backed — a current platform recommendation applies.
  4. Manual review — facts or editorial judgment are missing.

No numeric ranking potential is assigned to these classes.

Page and link graph

The bounded page layer checks inspectable facts such as canonical links, titles, H1 structure, language declaration, sampled inbound links, duplicate titles and generic anchor text. It intentionally avoids keyword density, word-count quality thresholds and universal internal-link quotas.

Reference machine plan · Methodology

After implementation

Every selected action carries a verification step and a measurement hook. The intended loop is observe → prioritize → review → implement → re-run → measure → keep/revise/revert. Search Console, structured-data checks and AI/referral evidence are measurements, not automatic proof of causality.
