Run against a real site

node bin/arwp-entities.mjs https://example.com
node bin/arwp-entities.mjs https://example.com --max-pages=20 --json
node bin/arwp-entities.mjs https://example.com --output=entity-gap-report.json

The crawl is bounded to same-site HTML discovered from the start page, crawlable links and sitemap URLs. A missing page outside that sample is not declared absent from the whole website.

What it detects

Person, Organization, Product, SoftwareApplication/WebApplication, Service, Dataset, Event-family, DefinedTerm and Article-family entities. For each entity ARWP checks stable identity, visible grounding, a useful observed entity page and graph relations.

Family-aware checks include Service provider, Dataset creator/publisher and license, Article author, Event start/location and DefinedTerm vocabulary membership.

What the report refuses to claim

This is not a ranking score, rich-result score, AI-citation probability, trust certificate or conversion model. It records structural evidence only. Closing a gap becomes a hypothesis whose outcome must be measured separately.
