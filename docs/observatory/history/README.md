# Protocol Observatory history

This directory is append-only historical evidence for the ARWP Agentic Web Protocol Observatory.

A new revision is created when a material same-day research correction changes protocol identity, discovery syntax, maturity or ARWP support classification. Older snapshots are not rewritten to match the newer interpretation.

For 2026-09-05:

- `2026-09-05.json` — r1, initial 10-mechanism snapshot.
- `2026-09-05-r2.json` — r2, expanded 16-mechanism research pass including ARD, DNS-AID, Web Bot Auth, AIPREF, NLWeb and auth.md.
- `2026-09-05-r3.json` — r3, ARD v0.91 correction using canonical `/.well-known/ard.json`, `rel="ard"` and JSON-LD description terminology while preserving predecessor ai-catalog compatibility.

Use `index.json` to resolve the newest revision. Do not infer that an older snapshot was incorrect in every respect; it records what ARWP had reviewed and published at that point in the loop.
