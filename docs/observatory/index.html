What changed recently

  • MCP released its 2026-07-28 specification generation with a stateless core and authorization hardening.
  • A2A's latest released specification is 1.0.0 and standardizes discovery through /.well-known/agent-card.json.
  • llms.txt v2 was modified on 2026-08-10 and explicitly recommends standard link relations including rel="describedby".
  • UCP published v2026-08-25, so agentic commerce is now a fast-moving protocol area rather than a distant placeholder.
  • WebMCP remains runtime-oriented; ARWP therefore tracks browser inspection as a separate R5 capability instead of pretending a static crawler can prove it.

Methodology boundary

This observatory records protocol/project facts and ARWP's implementation state. It does not measure web adoption, market share or protocol quality. A mechanism appearing here does not mean ARWP can execute it. Rows move to supported only when corresponding resolver/runtime behavior exists and is tested.
