  • RFC 9745: Deprecation HTTP response header

    Sections 2–5: header syntax and scope; deprecation links; Sunset; resource behavior — Defines the resource-scoped Deprecation date and deprecation documentation link; a signal does not itself change resource behavior.

  • RFC 8594: Sunset HTTP header
