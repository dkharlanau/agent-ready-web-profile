Publish distinct URLs for real language versions

One cookie-dependent URL can hide alternate language content.

What the review found

  • Managing multilingual and multi-regional sites

    Use different URLs for different language versions; Make sure the page language is obvious — Google recommends separate language URLs over cookie/browser-dependent substitution. Main content should match the language, rather than only translated boilerplate.

Make the change

  • Give each complete supported translation a stable URL.
  • Provide visible language navigation while retaining the selected locale.

Check the result

  • Each language URL serves the intended language without requiring a prior cookie.

Measure what happens

Track complete translated pages and locale-specific task completion.

Why try it

Stable language versions support access and discoverability.

multilingual-sites
