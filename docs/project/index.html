CONDITIONAL, NOT DECORATIVE

Do not publish policies you cannot honor.

Terms of service

Required by the Goose maturity profile only when the site actually has accounts, checkout, a paid hosted service, submissions or another contractual user workflow. The current static Goose site does not.

Status / SLA

Add a service-status or support-commitment page only when an availability or response promise exists. A static project site should not invent enterprise support language.

Accessibility statement

Accessibility is an implementation requirement. Publish a separate legal/commitment statement when an applicable duty or explicit public commitment has been established.

Financial & sponsorship disclosure

Disclose a material commercial relationship on the content or recommendation it can affect. Do not create a generic “independence” claim if the project has no evidence to support it.

Maturity is not page count. The profile asks for inspectable responsibilities. One consolidated page can satisfy several jobs when that is clearer; a site should not create thin legal-looking pages merely to resemble a large company.
