COPYRIGHT / LICENSES / REUSE

Permission needs a source.

A mature project should distinguish code licensing, content reuse, media permissions, crawler access and third-party material. One permissive file does not automatically grant rights over everything visible on a site.

Rights boundary

Software ≠ content ≠ third-party assets ≠ crawler policy

What applies where

Software source code

The repository software is licensed under the Apache License 2.0. The license text controls the granted software permissions and includes its own trademark provision.

Other project-authored web content

Use the explicit license or rights statement attached to the page, file or collection. This page does not create a blanket permission over material that is not included in a published license or rights manifest.

Third-party material

Third-party logos, trademarks, screenshots, quotations, fonts, source excerpts and other third-party material remain subject to their own rights and applicable law unless a separate permission says otherwise.

AI use and crawler access are separate

A robots rule controls technical access by a crawler within the scope of that mechanism. It does not itself grant copyright or reuse permission. Likewise, an open reuse license does not tell an automated fetcher to ignore robots, authentication, rate limits or other access controls.

Two questions, two answers. First: may a system technically fetch this surface? Second: what reuse rights apply to the material after lawful access? Goose keeps those facts separate.

Attribution, corrections and disputes

  • Preserve required attribution when reusing covered CC BY 4.0 material.
  • Do not remove third-party notices or imply that Goose grants rights it does not control.
  • Do not use an open-source license or open-media permission to imply endorsement, partnership or certification.
  • If a published factual ownership or attribution statement appears wrong, use the public corrections route.
  • Security reports belong in the security workflow, not in a copyright discussion.

What this page does not claim

This page is a project rights map, not a legal opinion, ownership registry or statement that every use is permitted. Applicable law, explicit license terms, third-party rights and the facts of a specific reuse still control.
