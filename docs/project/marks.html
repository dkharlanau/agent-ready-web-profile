How to refer to the project

  • Use Goose ARWP when the full public product identity matters.
  • Use Goose as the short form when the surrounding page already establishes the product identity.
  • Use Agent-Ready Web Profile (ARWP) when discussing the technical profile, repository, package, CLI or interoperability foundation.
  • Use module names only for the corresponding Goose module; do not turn a module into a separate company or certification.
  • Describe independent modifications as forks, adaptations or compatible implementations and identify their maintainer.

Affiliation boundary

Compatibility, citation, contribution, partnership discussion or use of an open-source component does not by itself mean endorsement, certification, employment, agency or approval by Goose ARWP, Metalhead Cats, an upstream protocol owner or another named provider.

No invented status. This project does not display a registered-trademark symbol for Goose ARWP and does not claim completed clearance. A domain search, repository policy or machine-readable naming manifest is not trademark registration.

Third-party marks

Third-party product, company and protocol names are used to identify their respective subjects. This project does not grant rights in third-party marks and should not style compatibility copy as co-branding unless an actual relationship authorizes it.
