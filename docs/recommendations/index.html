No ranking promise. ARWP does not claim that a manifest, score, llms.txt, WebMCP, structured data or any other single mechanism raises search ranking. It records upstream requirements and opportunities, then reports what can actually be observed.

Page semantics routing

ARWP now classifies a route before recommending markup. The goal is to let a repository agent turn a finding into a bounded patch instead of spraying a generic SEO template across the site.

Identity · Home

WebSite + publisher identity

Keep one coherent site identity and one real publisher Person/Organization identity, then reuse stable references rather than emitting conflicting copies.

Editorial · Authors

Article + resolvable authors

Use visible authorship/accountability, truthful dates and real author URLs. A ProfilePage is appropriate only when the page is genuinely about that contributor or organization.

Events

Unique event leaf pages

When targeting Google's event experience, each real event gets a useful unique detail URL focused on that event. Automation may build it only from real source facts.

Data

Dataset provenance

Use Dataset for genuine data assets and preserve creator, publisher, identifiers, license and distributions where known. Do not treat the type as generic “data page” markup.

Knowledge graph

DefinedTerm + DefinedTermSet

Real glossaries, methodologies and classifications can expose stable term identity and membership without pretending that Schema.org semantics automatically create a Google rich result.

URL contract

Canonical + sitemap + hreflang

Canonical links, internal links, sitemap inventory, indexability and real localized variants should agree. Avoid redirect/noindex/duplicate pollution in the canonical sitemap.

Designed for repository agents

Each page-level finding resolves into problem → evidence → risk → recommendedChange → files → autofix → verification → source. Autofix is allowed only when the repository already contains the facts required for the change. Missing author biography, event details, legal identity, price, rating, review or dataset provenance stays an owner-data gate.

Anti-cargo-cult rules

Structured data

Visible content before metadata

Do not install a universal JSON-LD bundle. Choose the type from the page's real job and keep machine facts consistent with visible content.

Retired feature

No sitelinks-search SearchAction cargo cult

Google removed the sitelinks search box globally in November 2024. Legacy feature-only markup can be removed; WebSite remains useful for supported site-name semantics.

Rich results

No universal FAQ/HowTo injection

Do not turn every article into FAQ/HowTo markup or fabricate reviews, ratings, offers or other properties in pursuit of a historical SERP treatment.

Freshness

No fake freshness

dateModified and sitemap lastmod should reflect meaningful changes, not every build or copyright-year update.

Existing Search + Agent layer

Google · AI search

Preferred Sources

Detect the official Preferred Sources integration. Treat it as a user-preference acquisition opportunity, never as a general ranking guarantee.

Google · Citation

Read more deep links

Keep stable heading IDs and avoid page-load code that destroys fragments or forces scroll-to-top behavior.

Preview policy

Snippet and image-preview controls

Observe nosnippet, max-snippet, data-nosnippet and max-image-preview as explicit publisher policy. Bing also documents data-nosnippet for AI-generated summaries.

Freshness

Sitemap lastmod + IndexNow

Observe sitemap freshness metadata and keep IndexNow as an explicit configured/receipt-based mechanism rather than guessing adoption from page markup.

Experimental

WebMCP, AIPREF and Introduction Layer

Keep runtime-only evidence separate and continue to label experimental/incubating mechanisms as such.

Measure effects instead of claiming them

Google Search Console generative-AI reporting and Bing Webmaster Tools AI Performance are external owner evidence. Public crawling cannot infer citation counts, grounding queries or AI impressions. Compare explicit before/after evidence while preserving negative results.
