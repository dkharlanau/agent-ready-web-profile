# Disallowing it does not block Google Search, but it restricts documented Gemini training / specified non-Search grounding uses.

Allow: /

Disallow: /

# Perplexity search indexing allowed. PerplexityBot is documented as not being used for foundation-model pretraining.

# Intentionally no Perplexity-User rule here: official Perplexity sources reviewed on 2026-09-05 are not fully consistent about current robots behavior for user-triggered retrieval.
