One map for the interfaces your website already has.

ARWP gives people, search systems, retrieval tools and AI agents a small machine-readable map of the real surfaces a site exposes — without pretending to replace SEO, MCP, WebMCP, Agent Skills, A2A, OpenAPI or llms.txt.

01

The problem

A site can expose everything correctly and still be difficult to integrate.

A sitemap tells a crawler where pages live. OpenAPI describes an API. SKILL.md describes a reusable procedure. MCP exposes tools or data. None of those is a complete inventory of the site's other interfaces. ARWP is a thin discovery layer over those existing contracts.

How it works

Observe → describe → verify.

  1. 01

    Observe

    The bounded scanner checks a small set of public HTTPS discovery surfaces and records evidence it can actually see.

  2. 02

    Describe

    arwp init creates a conservative draft profile. Unverified MCP, WebMCP, Agent Skills or A2A capabilities are not invented.

  3. 03

    Verify

    The schema validator checks the contract; the live verifier checks declared public resources; the GitHub Action keeps the profile valid in CI.

Capability groups

Different mechanisms stay different.

ARWP does not award points for adding more technologies. A small truthful profile is better than a large speculative one.

WEB

Web discovery

Canonical HTML, sitemaps, robots policy, feeds and optional llms.txt.

DATA

Data & APIs

Machine-readable records, schemas, OpenAPI, releases and dataset metadata.

RET

Retrieval

Bounded search/RAG distributions with stable identity, citations and explicit no-match behavior.

SKILL

Agent Skills

Real portable SKILL.md procedures. Instructions are not treated as a tool transport.

WEBMCP

Agent Web

Browser pages that actually expose structured WebMCP tools at runtime.

MCP

Model Context Protocol

Real local or remote MCP servers. Static JSON does not become MCP by declaration.

A2A

Agent-to-agent

An Agent Card is declared only when a real agent service exists behind it.

TRUST

Identity & trust

Stable IDs, licensing, provenance, review state and citation surfaces.

02

Evidence over badges

ARWP reports what was assessed, not a vanity readiness score.

detected The scanner has direct evidence for the surface.

warning A resource exists but its contract or metadata needs attention.

not assessed Static discovery cannot prove the runtime/protocol behavior.

Try with a site you already have

Generate the exact local scan commands.

The public browser UI does not proxy arbitrary websites. Enter a public HTTPS site and this page will prepare commands for the bounded scanner in the repository checkout.

cd agent-ready-web-profile
npm ci
2 · Inspect evidence

node bin/arwp.mjs init https://example.com

Boundaries

Small by design.

ARWP is useful only if its claims remain inspectable.

Not an SEO ranking mechanism. Search eligibility still depends on ordinary search and web fundamentals.

Not a permission layer. Metadata never grants crawler access, authorization or execution rights.

Not another MCP. The generic gateway is one ARWP consumer; the profile itself stays protocol-neutral.

Not a speculative catalog. New fields should come from concrete interoperability failures, not new AI terminology.
