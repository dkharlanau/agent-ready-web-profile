Citation and DOI status

No DOI is issued or claimed for these datasets. Cite the actual dataset title, maintainer, snapshot/version, landing URL and access date. Preserve the exact data bytes or a commit-pinned copy when a reproducible result depends on them. A moving download URL is not an immutable release.

Software citation remains separate in CITATION.cff. To obtain a dataset DOI, archive the reviewed data and metadata as a dataset record. Do not reuse a software DOI as if it identified a distinct dataset. A reserved identifier is not a published record.
