Start with a readable answer before adding AI discovery files

For documentation maintainers · Sources checked 8 September 2026

First make the page answer a real reader question, with its important qualifications and sources available as text. Then test whether an additional machine-readable representation helps the clients you actually support.

For a page to be eligible as a supporting link in Google's AI search features, it must be indexed and eligible for a search snippet. Eligibility does not guarantee that the page will be shown. [1]

Run one small check

  1. Choose one public guide and a question it should answer.
  2. Fetch the deployed page as ordinary HTML, extract its readable text, and identify the answer, its main condition, and its evidence link.
  3. Open the rendered page at a narrow viewport. Check that a reader can find the same answer and use the source link.
  4. If you offer Markdown or a JSON summary, compare those facts with the HTML. Record missing qualifications and contradictory values.

This is an ARWP verification proposal. It tests whether representations retain the answer; it does not measure Google indexing or ranking. JavaScript-rendered sites need an additional rendered-content check.

Add a representation only for a clear use

Google says additional AI text files and special schema are unnecessary for these search features. [1] A separate representation can still be a reasonable interoperability experiment for a client that reads it.

HTML permits private application metadata in data-* attributes. [2] The evidence attributes in this example are a local editorial convention. They provide no instruction to recommend this page and no documented ranking advantage.

When this check is not enough

A complete extracted answer can still be outdated, unsupported, or blocked by the actual crawler policy. A server response from a normal client cannot establish how a verified crawler was treated. Check claims, access policy, and provider observations independently.

Method and original contribution

The external claims were checked against the primary sources below. The four-step verification sequence and the HTML-to-receipt link convention are original ARWP proposals. This example contains no measured search result, customer result, or product-performance assertion.
