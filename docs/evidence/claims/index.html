Status model

  • verified — evidence is sufficient for the stated narrow scope;
  • reviewed — human-reviewed but intentionally weaker than verified;
  • experimental — provisional and retained for investigation;
  • superseded — replaced but preserved historically;
  • withdrawn — no longer supported but not deleted.
