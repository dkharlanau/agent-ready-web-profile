SHORT

SiteCurrent is an adaptive website improvement system built on the open-source Agent-Ready Web Profile (ARWP) project. It turns current Search, AI and agent guidance into site-specific, verifiable improvements.

STANDARD

SiteCurrent watches how Search, generative discovery, AI citation surfaces and web-agent practices change, checks what actually applies to a target website, and turns that evidence into concrete upgrade work: exact change surfaces, implementation recipes, verification contracts and follow-up measurement. Deterministic or explicitly grounded work can be promoted into digest-gated repository changes and reviewable pull requests, while editorial, policy, authenticated owner and runtime/security decisions stay gated. Agent-Ready Web Profile (ARWP) remains the open-source technical project, package and interoperability foundation.

TAGLINE

Keep your site ready for what finds it next.

RHYTHM

Found. Understood. Cited. Used.

STATUS

SiteCurrent / ARWP is in active, pre-stable development. The current repository toolchain is 0.2.0. SiteCurrent was introduced as the product-facing brand on 2026-09-07; ARWP remains the technical project identity.
