ARWP · Agent Skills

Run website improvement as an evidence loop, not a checklist.

Portable Agent Skills let an agent research current guidance, inspect a website repository, select explicit hypotheses, implement changes, verify the final artifact and keep Search-engine outcomes separate from repository state.

Default workflow: arwp-growth-loop. Before calling a public hostname ready, run arwp-search-release. Use arwp-search-maturity for current reference cohorts, arwp-braidgraph for provenance and arwp-future-search only for governed experiments after current foundations are healthy.

Install

npx skills add dkharlanau/agent-ready-web-profile

Boundary

These workflows make site improvement more systematic and testable. They do not guarantee ranking, Discover placement, AI citations, recommendations or traffic.

Search release is now a separate gate

Technical crawlability is necessary but not sufficient. A public hostname can still ship with the wrong site label, a rewritten title, utility text as the snippet, an unsuitable favicon, a mixed-host sitemap or stale production output. Search Release treats those as explicit release evidence and keeps actual engine selection as a later owner-observed step.

Search Release methodology

Provenance is not causality

BraidGraph records why a recommendation or change exists, what it depends on and which source/rule revisions make it a re-review candidate. Graph adjacency and timing do not prove that a change caused ranking, citation or traffic movement.

BraidGraph methodology

Reference patterns are evidence, not magic weights

Search Maturity keeps unmeasured dimensions unknown and requires separate evidence before storing numeric rank. It is designed to find repeated, potentially useful differences, not to label competitor characteristics as hidden ranking factors.

Search Maturity methodology

Future Search is deliberately separate

The Future Search specialist may add broader applicable Schema.org relations or optional semantic indexes when they improve truthful interoperability, but every experiment keeps explicit maturity, source review and verification. Metadata volume by itself is not a goal.
