ARWP · Agent Skills

Prepare a site with an AI agent.

Portable Agent Skills that let coding agents inspect an existing website, apply ARWP and current Search/AI/agent guidance, verify the result, and leave evidence instead of stopping at recommendations.

Default workflow: install the skill package, load arwp-prepare-site, let the agent inspect the repository, implement safe P0/P1 changes, then verify with ARWP audit, Growth Profile, assertions and receipts.

Install

npx skills add dkharlanau/agent-ready-web-profile

Agent Skills use progressive disclosure: the agent sees lightweight skill metadata first and loads the full workflow only when relevant.

Boundary

These workflows reduce technical and information-quality problems and make the site easier to discover, classify, cite and operate. They do not guarantee Google ranking, AI citations or recommendation placement.
