ARWP · Agent Skills

Run the website growth loop with an AI coding agent.

Portable Agent Skills let an agent research current evidence, inspect a website repository, select explicit hypotheses, implement changes, verify the result and preserve measurement evidence instead of stopping at recommendations.

Default growth workflow: arwp-growth-loop. For initial technical preparation, use arwp-prepare-site.

Install

npx skills add dkharlanau/agent-ready-web-profile

Boundary

These workflows make site improvement more systematic and testable. They do not guarantee ranking, Discover placement, AI citations, recommendations or traffic.
