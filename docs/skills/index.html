ARWP · Agent Skills

Run the website growth loop with an AI coding agent.

Portable Agent Skills let an agent research current evidence, compare relevant reference cohorts, inspect a website repository, select explicit hypotheses, implement changes, trace why those changes exist, verify the result and preserve measurement evidence instead of stopping at recommendations.

Default workflow: arwp-growth-loop. Use arwp-search-maturity for current reference cohorts, arwp-braidgraph for provenance/impact/evidence debt, and arwp-future-search only for governed experiments after current foundations are healthy.

Install

npx skills add dkharlanau/agent-ready-web-profile

Boundary

These workflows make site improvement more systematic and testable. They do not guarantee ranking, Discover placement, AI citations, recommendations or traffic.

Provenance is not causality

BraidGraph records why a recommendation/change exists, what it depends on, which source/rule revisions make it a re-review candidate, and whether implementation/outcome evidence is still missing. Graph adjacency and timing do not prove that a change caused a ranking, citation or traffic movement.

BraidGraph methodology

Reference patterns are evidence, not magic weights

Search Maturity keeps unmeasured dimensions unknown, preserves the exact observation surface and requires separate evidence before storing numeric rank. It is designed to find repeated, potentially useful differences—not to label competitor characteristics as hidden ranking factors.

Search Maturity methodology

Future Search is deliberately separate

Google's current rich-result gallery is not treated as the full boundary of useful machine semantics. The Future Search specialist may add broader applicable Schema.org relations or optional semantic indexes when they improve truthful interoperability, but every experiment keeps explicit maturity, source review and verification. Metadata volume by itself is not a goal.
