25 Aug 2026
CompletedOrigin

Project started

ARWP began as a small, inspectable discovery profile for websites exposing web, data, retrieval and agent-facing interfaces. The core principle was to describe real public capabilities rather than planned integrations.

Repository
25 Aug 2026
Releasedv0.1.0

Experimental baseline released

The first tagged release shipped the profile contract, JSON Schema, validator, live verifier, reusable GitHub Action and MCP gateway foundations. It established an immutable compatibility point while keeping the project explicitly experimental.

Release v0.1.0
25 Aug 2026
CompletedArchitecture

From “another manifest” to an evidence-backed resolver

The project changed direction on its first day. Instead of asking every website to adopt one new manifest, ARWP became a resolver across existing discovery mechanisms, preserving source authority, conflicts and fallbacks.

Resolver implementationPublic repositioning
28 Aug 2026
CompletedEvidence

Negative results became product input

Benchmark truth, live publisher drift and experiments were separated. A no-gain A2A scope experiment was retained as evidence rather than quietly turned into a new rule. That established a useful governance constraint: new fields need observed failures.

Retained negative result
31 Aug 2026
CompletedAdoption

Consumer onboarding was hardened

A tested local onboarding path and package-boundary fixes made it possible to evaluate ARWP from a clean consumer setup instead of only from the project repository.

History and multilingual agent discovery

ARWP now exposes this product record and a machine-readable history, plus canonical English and localized German/Russian llms.txt routing surfaces. The translations help multilingual discovery without forking the normative specification: technical contracts, field names and protocol semantics remain canonical in English.
