How we learn / 6 September 2026

Measure use, not file count.

We want to know whether people can find useful ARWP pages, do something useful with them and adopt the project elsewhere. We keep those signals separate instead of turning them into one magic score.

Where we are now

We have the definitions, but not enough verified outcome data to claim results yet. The site already has an optional measurement layer, but this page does not assume it is active or complete everywhere. The extra events described in the plan are specifications, not proof that they are running.

When we do not know a baseline, we leave it unknown instead of turning it into zero. This page is a way to learn carefully, not a claim that growth has already happened.

Three signals worth separating

People find the right pages

Count clicks for disclosed queries classified by a versioned brand rule in an owner Search Console export. Keep Bing separate. Segment comparable landing pages and disclose missing query coverage. Use this to decide which relevant topics deserve better resources, not more near-duplicate pages.

People act on useful resources

Divide observed consented landing sessions with a dataset, template or repository click by observed consented landing sessions in the same cohort. A zero denominator gives no rate. Clicks are intent proxies, not completed downloads, installations or research citations.

Independent projects use it

Count distinct independently maintained projects with reviewed public or permissioned evidence of actual use. Exclude the maintainer's own reference sites and unverified declarations. Stars and package downloads do not substitute for an adoption review.

Definitions, grains, sources, limitations and event contract

Payload boundary

Proposed events cover dataset and template clicks, repository opens, citation copies and completed audits. Dimensions must be publisher-controlled identifiers, resource types, locale and coarse source group.

Do not send raw URLs, query strings, fragments, referrers, emails, search text, form contents or user-submitted audit targets. Review actual network payloads; a configuration declaration alone cannot prove this boundary is enforced.

Before making a result public

Verify the provider account and page coverage, document retention and the deployed privacy notice, test acceptance, rejection and withdrawal, and check for duplicate page views. Publish only reviewed aggregates. Do not publish raw query or visitor exports into this repository.

Compare complete matched 28-day windows. Record release changes, coverage and seasonality. A before/after difference is an observation, not proof that metadata caused it.
