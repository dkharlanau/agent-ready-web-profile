Learning from real results

Did the change help anyone?

A new page or a passing audit is only a starting point. We look for signs that someone found what they needed and could act on it. If a change had no visible effect, we want to know that too.

What we know so far

We can explain what to look at, but we do not yet have enough checked results to claim that Goose has increased traffic or adoption. Some optional visit statistics may be available when visitors agree. Other measurements in our plan are still proposals, not things we can claim to be tracking today.

If we haven't measured something, we say so. Unknown does not mean zero.

Three questions worth asking

Are people finding the useful pages?

Look at which pages people discover for relevant searches. If a useful guide is missing from those searches, improve the guide or how visitors reach it. Don't make five nearly identical pages just to target five phrases.

How we check this

Use dated, owner-authorized search reports. Keep search services, brand queries, page groups and missing data separate. A report without query coverage cannot support a complete query-level claim.

Can visitors take the next useful step?

A visit is promising, but it matters more when someone opens the relevant example, resource or project. See whether that next step happens. A click is not proof that they finished using it.

How we check this

Compare observed, permission-compatible visits and resource clicks for the same pages and dates. With no measured visits, no rate can be calculated.

Is anyone putting it to work independently?

A mention or a star is encouraging, but it's not the same as a project actually using the tool. We look for examples we can verify, and we don't count our own test sites as independent adoption.

Definitions, grains, sources, limitations and event contract

What we collect — and what we avoid

If we measure an action, it should be something simple, such as opening an example or copying a citation. We don't need the visitor's private content to learn which resources people use.

Our implementation rules exclude raw page query strings, referrers, emails, search text, form contents and submitted audit targets from custom events. We still have to inspect real network requests: a written rule does not prove it is followed.

Before we say a change worked

We check which pages were measured, whether permission choices work and whether any visits were counted twice. Only reviewed totals belong in public reports, never individual visitors or private search records.

When possible, compare complete 28-day periods on a like-for-like basis, allowing for slow reporting and seasonal demand. If visits rise, that alone does not prove our change caused it.
